# 2D Art Pipeline

Respect Chigüibara's identity: handmade-feeling, playful kawaii with personality. Avoid generic AI aesthetics, visual clutter, and an excessively childish look.

Inventory existing assets first, then define the minimum set:
- Chigüi poses and states;
- reusable animations;
- food and interactive objects;
- accessories that visibly change the character;
- optional background and decorations;
- UI icons.

Specify formats, relative sizes, pivots, naming, and required states only after the game engine and art tools are known. Reuse assets where possible. Do not generate or replace artwork without explicit approval.
